# Private Network Dimensioning Calculator

Static browser application converted from the Excel dimensioning calculator.

## Modules

- Scenarios
- Required Sectors
- Devices database

## Local Use

Open `index.html` in a browser.

## GitHub Pages

This repository includes a GitHub Actions workflow that publishes the static app to GitHub Pages whenever changes are pushed to `main`.

After pushing to GitHub, open the repository settings, go to **Pages**, and make sure the source is set to **GitHub Actions**.
